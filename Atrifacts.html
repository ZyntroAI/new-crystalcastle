🎀 Obsidian Ribbon — Visual Guide

Click any icon on the ribbon to see detailed information and API code examples

🏷️ Icon Categories

Core Icons — Built-in Obsidian features
Plugin Icons — Added by your own plugins
Community Icons — From community plugins

👈 Click an icon to see details

Each ribbon icon can be added via the Obsidian API. Hover over icons to see their labels and descriptions.

💻 How to Add Ribbon Icons

this.addRibbonIcon(
  'lucide-icon-name', 'Display Name',
  (evt: MouseEvent) => {
    new Notice('Clicked!');
  }
);

Icons are listed top-to-bottom in the order they're registered. Core icons appear first, then plugins.

React 19 Dependency Cleanup

Dependency update and CI recommendations for ZyntroAI/new-crystalcastle.

1. React Type Definitions

Recommended: Upgrade @types/react from React 18 types to React 19 types.

The project already uses React 19 at runtime: 

{
  "react": "^19.2.8",
  "react-dom": "^19.2.4"
}

Therefore the TypeScript definitions should be aligned with React 19. 

{
  "@types/react": "^19.2.18",
  "@types/react-dom": "^19.2.4"
}

English: The runtime is already using React 19, so keeping @types/react on React 18 creates an unnecessary type-definition mismatch.

3. Remove Tool Versions from devDependencies

Cleanup: Node.js, npm, and Yarn should not be declared as normal project development dependencies.

Remove:

"npm": "10.8.2",
"yarn": "1.22.22",
"node": "26.5.1"

These are environment/runtime tools rather than application packages.

4. Use engines

Define supported Node.js and npm versions using engines. 

"engines": {
  "node": ">=22 <27",
  "npm": ">=10"
}

The CI environment should then explicitly select the Node.js version used for builds.

5. React Dependency Alignment

React 19
├── react@19.2.8
├── react-dom@19.2.4
├── @types/react@19.2.18
└── @types/react-dom@19.2.4
        │
        ▼
    TypeScript
        │
        ▼
      Vite

This keeps runtime packages and TypeScript declarations aligned.

6. Update the Lockfile

After modifying package.json, regenerate the lockfile. 

npm install

Then verify the installed versions:

npm ls react react-dom @types/react @types/react-dom

The dependency tree should contain React 19-compatible versions.

react@19.x
react-dom@19.x
@types/react@19.x
@types/react-dom@19.x

"scripts": {
  "dev": "vite",

  "test": "vitest run",
  "test:watch": "vitest",
  "preview": "vite preview"
}

The test scripts should be included when Vitest is installed in the repository.

8. GitHub Actions CI

name: CI

on:
  pull_request:
  push:
    branches:
      - main

jobs:
  validate:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v5

      - name: Setup Node
        uses: actions/setup-node@v5
        with:
          node-version: 22
          cache: npm

      - name: Install
        run: npm ci

      - name: Typecheck
        run: npm run typecheck

      - name: Lint
        run: npm run lint

      - name: Test
        run: npm test

      - name: Build
        run: npm run build

9. CI Pipeline

Pull Request │ ▼ npm ci │ ▼ typecheck │ ▼ lint │ ▼ test │ ▼ build │ ▼ PASS │ ▼ MERGE

typecheck is particularly important for an @types/react update because type incompatibilities can appear during compilation even when the runtime React version does not change.

10. Dependency Update Checklist

  • Upgrade @types/react to 19.2.18.
  • Keep React runtime packages on React 19.
  • Keep @types/react-dom on React 19.
  • Remove Node.js from devDependencies.
  • Remove npm from devDependencies.
  • Remove Yarn from devDependencies.
  • Add Node.js and npm constraints under engines.
  • Regenerate package-lock.json.
  • Run npm ci.
  • Run npm run typecheck.
  • Run npm run lint.
  • Run tests.
  • Run npm run build.

11. Final Recommendation

Recommended: Accept the @types/react 18 → 19 update because the application is already using React 19.

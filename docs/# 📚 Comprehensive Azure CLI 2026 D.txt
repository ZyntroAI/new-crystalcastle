## 🔧 Installation, Versioning & Environment Setup
### Official Install Methods (Ubuntu/Debian, RHEL, Windows, macOS)
```bash
# 🐧 Ubuntu/Debian (Recommended)
curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash
# Verify GPG signature (critical for security)
gpg --keyserver hkp://keyserver.ubuntu.com --recv-keys 0EBFCD88

# 🐧 RHEL/CentOS/Fedora
sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
sudo dnf config-manager --add-repo https://packages.microsoft.com/yumrepos/azure-cli

# 🍎 macOS (Homebrew)
brew update && brew install azure-cli

# 🪟 Windows (PowerShell — Admin)
winget install --id Microsoft.AzureCLI -e --source winget
```

### Version Management & Environment Config
```bash
# Check full version & dependencies
az --version  # Output: azure-cli                         2.70.0
              # core                                      2.70.0
              # telemetry                                  1.1.0

# Upgrade to latest stable (safe for production)
az upgrade --yes --all  # --all = update all extensions too

# Configure default settings (persistent)
az configure --defaults \
  group=rg-production \
  location=southeastasia \
  output=table \
  subscription="Pay-As-You-Go"

# List active configuration
az configure --list-defaults
```

## 🔐 Authentication & Identity — 2026 Security Standards
### Auth Methods (Ranked by Security)
```bash
# 1️⃣ ✅ BEST: Managed Identity (No credentials stored)
az login --identity  # System-assigned MI
az login --identity --client-id <USER_MI_ID>  # User-assigned MI

# 2️⃣ Standard Interactive (Browser-based)
az login --allow-no-subscriptions  # List all tenants first

# 3️⃣ Headless / Remote (No GUI)
az login --use-device-code  # Output: https://microsoft.com/devicelogin + code

# 4️⃣ Service Principal (CI/CD — Use OIDC instead!)
az login --service-principal \
  --username $AZURE_CLIENT_ID \
  --password $AZURE_CLIENT_SECRET \
  --tenant $AZURE_TENANT_ID

# Account & Tenant Verification
az account show --output jsonc  # Clean JSON output
az account list --output table  # All subscriptions
az ad signed-in-user show --query "displayName, userPrincipalName"
```

### Secure Logout & Cleanup
```bash
az logout --username "user@domain.com"
az account clear  # Remove all cached credentials
az cache purge  # Clear token cache
```

## 📝 Command Structure, Output Formats & JMESPath Query Language
### Standard Syntax & Output Options
```
# Structure: az <resource-group> <operation> <sub-resource> [--flags]
az [group] [subgroup] [command] {parameters} [--output {json|table|tsv|yaml|none}]
```

| Output Format | Use Case | Example |
|---|---|---|
| `--output json` | Machine parsing, full data | `az vm list --output json` |
| `--output table` | Human-readable summary | ✅ Default recommended |
| `--output tsv` | Scripting, piping to other tools | No headers |
| `--output yaml` | IaC, config comparison | `--output yamlc` = clean |
| `--output none` | Silent mode (exit code only) | Error checking |

### JMESPath — Full Deep Dive
```bash
# Basic Selection
az vm list --query "[].{Name:name, Region:location, State:powerState}"

# Filtering (String/Boolean/Numeric)
az vm list --query "[?location=='southeastasia']"
az vm list --query "[?powerState=='VM running' && storageProfile.osDisk.diskSizeGb > 30]"

# Sorting & Grouping
az group list --query "sort_by(@, &name)"  # Ascending
az vm list --query "reverse(sort_by(@, &name))"  # Descending

# Nested Properties & Functions
az vm list --query "[].{Size: hardwareProfile.vmSize, IP: privateIps[0]}"
az vm list --query "length(@)"  # Count items
az vm list --query "sum(map(@, &hardwareProfile.memoryMb))"  # Aggregate
```

## 🖥️ Compute — Virtual Machines, Scale Sets & Containers
### VM Complete Workflow
```bash
# Create Secure (SSH Key, No Password)
az vm create \
  --resource-group rg-prod \
  --name vm-api-01 \
  --image Canonical:UbuntuServer:22.04-LTS:latest \
  --size Standard_D4s_v5 \
  --admin-username azureuser \
  --generate-ssh-keys \
  --public-ip-sku Standard \
  --security-type TrustedLaunch  # ✅ Secure Boot Enabled

# Management
az vm start --name vm-api-01 -g rg-prod --no-wait
az vm restart --name vm-api-01 -g rg-prod
az vm deallocate --name vm-api-01 -g rg-prod  # Stop + Free Resources
az vm generalize --name vm-api-01 -g rg-prod  # For Image Capture

# Diagnostics
az vm list-ip-addresses --name vm-api-01 -g rg-prod
az vm get-instance-view --name vm-api-01 -g rg-prod --query "instanceView.statuses"
```

## ☸️ Kubernetes — AKS Full Lifecycle & OIDC Integration
### Production-Grade AKS
```bash
# Create with OIDC & Security
az aks create \
  --resource-group rg-aks \
  --name aks-main \
  --node-count 3 \
  --kubernetes-version 1.30.3 \
  --enable-oidc-issuer \
  --enable-managed-identity \
  --network-plugin kubenet \
  --load-balancer-sku Standard \
  --tags Project=PureAgent

# Credentials & Access
az aks get-credentials --name aks-main -g rg-aks --overwrite-existing
az aks check-acr --name aks-main --acr acrpureagent

# Upgrade & Scale
az aks upgrade --name aks-main -g rg-aks --version 1.31.0
az aks scale --name aks-main -g rg-aks --node-count 5
```

## 🔄 CI/CD Integration — GitHub Actions OIDC & Secrets
```yaml
name: Azure Deployment
on: [push, pull_request]
permissions:
  id-token: write   # ✅ Required for OIDC (No Client Secret!)
  contents: read
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Azure Login
        uses: azure/login@v2
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
```

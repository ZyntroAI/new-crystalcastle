## ⚙️ ขั้นตอนถัดไป — ตั้งค่า CI/CD ตรวจสอบอัตโนมัติ

### 1. สร้างไฟล์ตรวจสอบ PR — `.github/workflows/pr-checks.yml`
```yaml
name: PR Validation Gatekeeper

on:
  pull_request:
    types: [opened, edited, synchronize, ready_for_review]

jobs:
  checklist-validation:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: 📋 Validate PR Checklist
        uses: actions/github-script@v7
        with:
          script: |
            const body = context.payload.pull_request.body || '';
            const checks = [
              '- [ ] Code builds locally',
              '- [ ] Tests added / updated',
              '- [ ] Documentation updated',
              '- [ ] CI/CD pipeline passes',
              '- [ ] No secrets committed'
            ];
            const missing = checks.filter(c => !body.includes(c));
            if (missing.length > 0) {
              core.setFailed(`❌ Missing checklist items:\n${missing.join('\n')}`);
            } else {
              core.info('✅ All checklist items present');
            }

  secrets-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: fetch-depth: 0
      - name: 🔍 Scan for secrets
        uses: gitleaks/gitleaks-action@v2
        with:
          args: --baseline-path .gitleaks-baseline.json --verbose

  conventional-title:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/github-script@v7
        with:
          script: |
            const title = context.payload.pull_request.title;
            const valid = /^(feat|fix|docs|security|infra|chore|release)(\(.+\))?!?: .+/i.test(title);
            if (!valid) {
              core.setFailed('❌ Title must follow Conventional Commits: feat(area): desc, fix(area): desc, etc.');
            }
```

### 2. ตั้งค่า Branch Protection Rules
ใน GitHub → Repo → Settings → Branches → Add rule:
- **Branch name pattern:** `main`
- ✅ Require status checks to pass → เลือก `pr-checklist`, `secrets-scan`, `conventional-title`
- ✅ Require pull request reviews before merging → 1 approval ขั้นต่ำ
- ✅ Do not allow bypassing the above
- ✅ Include administrators

เพิ่ม ตัวอย่างไฟล์ .gitleaks.toml
จัดให้ครบครับ 🎯 — เพิ่มตัวอย่างไฟล์ .gitleaks.toml ซึ่งเป็น config หลักของ Gitleaks สำหรับควบคุม rule set และการสแกน secrets ใน repo ของคุณ

📄 .gitleaks.toml
toml
title = "Gitleaks Config"
version = "2.0"

[allowlist]
description = "Global allowlist for known safe patterns"
regexes = [
  "dummy_secret",
  "example_api_key",
  "test_password",
  "not_a_real_token"
]
paths = [
  "docs/",
  "examples/",
  "tests/"
]

[[rules]]
id = "generic-api-key"
description = "Generic API Key"
regex = '''(?i)(api[_-]?key|apikey|secret)[=:]\s*['"]?[0-9a-zA-Z]{32,}['"]?'''
tags = ["apikey", "secret"]

[[rules]]
id = "aws-access-key"
description = "AWS Access Key"
regex = '''AKIA[0-9A-Z]{16}'''
tags = ["aws", "key"]

[[rules]]
id = "aws-secret-key"
description = "AWS Secret Key"
regex = '''(?i)aws(.{0,20})?(secret|access)[_-]?(key)?(.{0,20})?['"][0-9a-zA-Z/+]{40}['"]'''
tags = ["aws", "secret"]

[[rules]]
id = "private-key"
description = "Private Key"
regex = '''-----BEGIN( RSA)? PRIVATE KEY-----'''
tags = ["key", "private"]

[[rules]]
id = "github-token"
description = "GitHub Token"
regex = '''ghp_[0-9a-zA-Z]{36}'''
tags = ["github", "token"]

[[rules]]
id = "slack-token"
description = "Slack Token"
regex = '''xox[baprs]-[0-9a-zA-Z]{10,48}'''
tags = ["slack", "token"]

[[rules]]
id = "google-api-key"
description = "Google API Key"
regex = '''AIza[0-9A-Za-z\\-_]{35}'''
tags = ["google", "apikey"]

[[rules]]
id = "heroku-api-key"
description = "Heroku API Key"
regex = '''[0-9a-fA-F]{32}'''
tags = ["heroku", "apikey"]

การทำงานกับไฟล์ที่ไม่ใช่โค้ดใน GitHub

GitHub รองรับการแสดงผล การดู และการเปรียบเทียบไฟล์หลายประเภทที่ไม่ใช่ซอร์สโค้ดโดยตรงภายใน Repository เช่น รูปภาพ โมเดล 3 มิติ ไฟล์ CSV/TSV เอกสาร PDF เอกสารข้อความ แผนที่ Jupyter Notebook และ Mermaid Diagram

ไฟล์รูปภาพ (Image Files)

GitHub รองรับไฟล์รูปภาพยอดนิยม ได้แก่

PNG
JPG/JPEG
GIF
PSD
SVG
หมายเหตุ
GitHub สามารถแสดงไฟล์ PSD ได้ แต่ไม่รองรับการเปรียบเทียบความแตกต่างระหว่างเวอร์ชัน
SVG อาจแสดงผลไม่สมบูรณ์ในบางเวอร์ชันของ Firefox
SVG ไม่รองรับการใช้ Inline Script หรือ Animation
โหมดการเปรียบเทียบรูปภาพ

GitHub มีโหมดเปรียบเทียบรูปภาพ 3 รูปแบบ ได้แก่

1. 2-Up View (ค่าเริ่มต้น)

แสดงรูปภาพทั้งสองเวอร์ชันเคียงข้างกัน พร้อมแสดงความแตกต่างของขนาดรูปภาพหากมีการเปลี่ยนแปลง ทำให้มองเห็นการปรับขนาดหรือการเปลี่ยนความละเอียดได้อย่างชัดเจน

2. Swipe View

ใช้แถบเลื่อนเพื่อเปรียบเทียบภาพสองเวอร์ชันแบบซ้อนกัน เหมาะสำหรับตรวจสอบความแตกต่างของสีหรือรายละเอียดเล็ก ๆ

3. Onion Skin View

ซ้อนภาพทั้งสองเวอร์ชันทับกันพร้อมปรับระดับความโปร่งใส ช่วยให้สังเกตการเคลื่อนย้ายหรือการจัดวางองค์ประกอบที่เปลี่ยนไปเพียงเล็กน้อยได้ง่าย

ไฟล์ 3 มิติ (.stl)

GitHub สามารถแสดงโมเดล 3 มิติในรูปแบบ STL ได้

การควบคุมโมเดล
คลิกและลากเพื่อหมุนโมเดล
คลิกขวาและลากเพื่อเลื่อนมุมมอง
ใช้ Scroll เพื่อซูมเข้า/ออก
เปลี่ยนโหมดการมองเห็นตามต้องการ
ข้อกำหนดและข้อจำกัด
เบราว์เซอร์ต้องรองรับ WebGL
Chrome และ Firefox รองรับ WebGL โดยค่าเริ่มต้น
ไฟล์ STL ที่ไม่ถูกต้องอาจไม่สามารถแสดงผลได้
GitHub ไม่สามารถแสดงไฟล์ที่มีขนาดเกิน 10 MB
การฝัง (Embed) โมเดล STL

สามารถฝังโมเดล STL ลงในหน้าเว็บ HTML ได้ผ่าน URL รูปแบบต่อไปนี้

https://embed.github.com/view/3d/<username>/<repo>/<ref>/<path_to_file>script>


ตัวอย่าง

<script src="https://embed.github.com/view/3d/skalnik/secret-bear-clip/master/stl/clip.stl"></script>


สามารถกำหนดขนาดได้ เช่น

>/<ref>/<path>?height=300&width=500"></script>


หมายเหตุ: ref สามารถเป็นชื่อ Branch หรือ Commit Hash ได้

ขนาดไฟล์เกินกำหนด

ใช้ตัวคั่นที่ไม่รองรับ

GitHub รองรับเฉพาะ Comma และ Tab เท่านั้น ไม่รองรับตัวคั่นประเภทอื่น เช่น Semicolon (;)

Jupyter Notebook (.ipynb)

GitHub สามารถแสดงไฟล์ Jupyter Notebook และ IPython Notebook เป็นหน้า HTML แบบ Static

หมายเหตุ

หากต้องการใช้งานแบบ Interactive ควรใช้ NBViewer หรือรัน Jupyter Notebook Server ด้วยตนเอง
แปลง Notebook เป็น HTML

ใช้คำสั่งดังนี้

jupyter nbconvert --to html NOTEBOOK-NAME.ipynb

คุณสมบัติ
แสดงผล Diagram อัตโนมัติภายใน Repository
สามารถฝัง Mermaid Syntax ใน Markdown ได้โดยตรง
ข้อจำกัดที่ทราบ
Sequence Diagram อาจมีพื้นที่ว่างด้านล่างมากกว่าปกติ
บางองค์ประกอบแบบ Interactive อาจทำงานไม่สมบูรณ์
Diagram บางประเภทอาจยังไม่รองรับการเข้าถึง (Accessibility) อย่างครบถ้วน
การแก้ไขปัญหา
ตรวจสอบ Syntax ผ่าน Mermaid Live Editor
หากยังพบปัญหา สามารถเปิด Issue พร้อมติดป้ายกำกับ (Label) Mermaid เพื่อรายงานปัญหา

## 🏗️ ขั้นตอนและโครงสร้างที่จะสร้าง

### ขั้นที่ 1: โมเดลและโครงสร้างข้อมูล
> สร้างคลาสแท่นและจาน
- [ ] `HanoiDisk.cs` — สี, ขนาด, ความกว้าง
- [ ] `HanoiTower.cs` — รายการจาน, ตรวจวางได้/ไม่ได้
- [ ] `HanoiEngine.cs` — ตรรกะการย้ายจานและตรวจสอบกฎ

### ขั้นที่ 2: ตรรกะหลักและบริการ
> พัฒนาเอนจินควบคุม
- [ ] เมธอด `MoveDisk(from, to)` — ตรวจกฎ → ย้ายถ้าได้
- [ ] เมธอด `Reset(diskCount)` — เริ่มต้นใหม่ จานทั้งหมดที่แท่นซ้าย
- [ ] เมธอด `IsSolved()` — ตรวจสอบว่าชนะแล้วหรือยัง

### ขั้นที่ 3: ส่วนติดต่อผู้ใช้
> สร้างหน้าต่างหลักและการแสดงผล
- [ ] `MainWindow.xaml` — พื้นหลัง, 3 แท่น, พื้นที่จาน
- [ ] แสดงจานตามขนาดและสี → คำนวณความกว้างแบบไดนามิก
- [ ] จานเลข 1 (เล็กสุด) อยู่บนสุด, จานใหญ่สุดอยู่ล่างสุด

### ขั้นที่ 4: การควบคุมและการโต้ตอบ
> ปุ่มและการควบคุม
- [ ] ปุ่ม: ▶ เล่น, ⏸ หยุด, ⏭ ขั้นตอนถัดไป, ↻ รีเซ็ต
- [ ] แสดงสถานะ: ขั้นที่แล้ว / จำนวนครั้งที่ย้าย
- [ ] ธีมตามระบบ Windows 11 (Fluent)

### ขั้นที่ 5: การทดสอบและการตรวจสอบ
- [ ] ย้ายจานเล็กไปวางบนจานใหญ่ → ต้องทำได้
- [ ] พยายามย้ายจานใหญ่ไปวางบนจานเล็ก → ต้องปฏิเสธ
- [ ] ย้ายจานจนครบที่แท่นขวา → ต้องตรวจพบว่าสำเร็จ

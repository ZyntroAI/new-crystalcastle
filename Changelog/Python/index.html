GitHub Actions Strategy

Python versions should be tested through a CI matrix rather than relying on a single local environment. 

strategy:
  matrix:
    python-version:
      - "3.13"
      - "3.14"

A backend project can then validate installation, linting, type checking, tests, and packaging across supported Python versions.

Upgrade Workflow

  1. Review the official Python What's New documentation.
  2. Review deprecated and removed functionality.
  3. Review framework compatibility.
  4. Update the Python runtime.
  5. Update dependency constraints.
  6. Run the complete test suite.
  7. Validate Docker builds.
  8. Validate GitHub Actions.
  9. Merge only after CI passes.

Upgrade Checklist

  • Review Python What's New
  • Review Python changelog
  • Review deprecations
  • Review removed APIs
  • Check FastAPI compatibility
  • Check dependency compatibility
  • Update Docker image
  • Update CI Python matrix
  • Run tests
  • Run linting
  • Run type checking
  • Run production build
